# 吵架记录小程序

一个帮助夫妻通过记录和分析吵架，深入了解彼此需求，改善沟通关系的微信小程序。

## 项目简介

通过AI技术分析吵架录音，提供：
- 📊 情绪变化曲线
- ⚡ 吵架触发点识别
- 💭 双方需求分析（表层/深层）
- 💬 沟通模式分析
- ☁️ 高频关键词统计

## 功能特点

- ✅ **隐私优先**：录音识别后立即删除，数据默认本地存储
- ✅ **AI深度分析**：使用智谱GLM进行多维度分析
- ✅ **可视化展示**：ECharts图表直观展示
- ✅ **离线可用**：所有数据本地存储，无需联网查看历史记录

## 技术栈

- **前端**：微信小程序原生开发
- **后端**：微信云开发
- **语音识别**：腾讯云语音识别API
- **AI分析**：智谱GLM-4 API
- **图表**：ECharts for 微信小程序

## 快速开始

### 1. 前置准备

- 注册微信小程序账号
- 开通微信云开发
- 申请腾讯云账号（用于语音识别）
- 申请智谱AI账号（用于AI分析）

### 2. 配置云开发

1. 用微信开发者工具打开项目
2. 点击"云开发"按钮，创建云开发环境
3. 记录环境ID，替换 `app.js` 中的 `your-env-id`

### 3. 配置云函数环境变量

在云开发控制台中，为每个云函数配置环境变量：

**voice-recognize 云函数：**
```
TENCENT_SECRET_ID=your_secret_id
TENCENT_SECRET_KEY=your_secret_key
TENCENT_REGION=ap-guangzhou
```

**ai-analysis 云函数：**
```
ZHIPU_API_KEY=your_zhipu_api_key
```

### 4. 安装云函数依赖

在微信开发者工具中：
1. 右键点击 `cloudfunctions/voice-recognize`
2. 选择"在终端中打开"
3. 运行 `npm install`
4. 重复步骤2-3安装 `ai-analysis` 的依赖

### 5. 上传并部署云函数

1. 右键点击每个云函数目录
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 6. 下载ECharts

```bash
cd components/ec-canvas
# 下载 echarts.min.js
wget https://cdn.jsdelivr.net/npm/echarts@5.4.3/dist/echarts.min.js
```

### 7. 配置小程序AppID

在 `project.config.json` 中替换 `your-appid` 为你的小程序AppID

### 8. 运行项目

1. 在微信开发者工具中点击"编译"
2. 在模拟器中预览效果
3. 或扫描真机预览二维码测试

## API密钥申请

### 腾讯云语音识别

1. 访问 [腾讯云语音识别](https://cloud.tencent.com/product/asr)
2. 开通服务（有免费额度）
3. 创建API密钥：访问密钥管理
4. 记录 SecretId 和 SecretKey

### 智谱AI

1. 访问 [智谱AI开放平台](https://open.bigmodel.cn/)
2. 注册并登录
3. 创建API Key
4. 记录API Key

## 使用说明

### 添加吵架记录

1. 吵架时用手机自带"录音机"录制
2. 吵架后打开小程序，点击"添加"
3. 选择录音文件
4. 等待AI分析完成（约50秒）
5. 查看分析结果

### 查看分析

- **情绪曲线**：点击曲线上的点查看对应对话
- **触发点**：了解吵架的导火索
- **需求分析**：理解双方的真实需求
- **沟通模式**：发现沟通问题
- **关键词**：查看高频话题

### 隐私设置

在"设置"页面可以：
- 选择数据存储位置（本地/云端）
- 设置通知时机
- 导出/删除数据

## 注意事项

1. **测试音频**：项目根目录下有测试音频文件 `吵架对话_完整版.mp3`
2. **成本控制**：
   - 语音识别：每月10小时免费
   - GLM API：按token计费，约0.1-0.5元/次
3. **隐私保护**：
   - 录音文件识别后会自动删除
   - 建议使用本地存储模式
4. **性能优化**：
   - 建议录音时长控制在5分钟以内
   - 过长的录音会增加处理时间和成本

## 常见问题

**Q: 云函数调用失败？**
A: 检查环境变量是否配置正确，云函数是否已部署

**Q: 语音识别不准确？**
A: 使用高质量的录音设备，确保环境安静

**Q: AI分析结果不理想？**
A: 可以调整Prompt模板，或升级到更强的模型

**Q: 图表不显示？**
A: 确保echarts.min.js已下载并放在正确位置
